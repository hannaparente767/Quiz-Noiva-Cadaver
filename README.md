# 💀 Quiz — A Noiva Cadáver

Um quiz interativo inspirado no universo de **A Noiva Cadáver**, desenvolvido durante o meu **2º período de Sistemas de Informação**, quando eu estava começando a aprender desenvolvimento web.

A ideia surgiu da vontade de aprender programação de uma maneira mais divertida, unindo os conteúdos que eu estava estudando com algo que gosto: o universo de **Tim Burton e suas animações**.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- 💀 Quiz interativo sobre A Noiva Cadáver
- ❓ Perguntas com alternativas
- 🎯 Sistema de respostas
- 📊 Resultado do quiz
- 🎨 Interface inspirada na estética do universo de Tim Burton
- 🖱️ Interações utilizando JavaScript

## 📚 Sobre o projeto

Este foi um dos meus primeiros projetos desenvolvidos durante a graduação e surgiu como uma forma de tornar o aprendizado de **HTML, CSS e JavaScript** mais divertido e significativo.

Na época, eu estava começando a aprender os fundamentos do desenvolvimento web e decidi transformar um tema que gosto em um projeto de programação.

Escolhi o universo de **A Noiva Cadáver** e as animações de **Tim Burton** como inspiração para criar a identidade visual e as perguntas do quiz.

## 🎯 Objetivo

Praticar os primeiros conceitos de desenvolvimento web por meio de um projeto que combinasse **programação e criatividade**.

O projeto também foi uma forma de experimentar como os conhecimentos aprendidos em sala poderiam ser utilizados para criar algo interativo.

## 🧠 O que pratiquei

Durante o desenvolvimento, pude praticar:

- Estruturação de páginas com HTML
- Estilização com CSS
- Lógica de programação com JavaScript
- Manipulação de elementos da página
- Eventos e interações
- Estruturação de perguntas e respostas
- Criação de uma interface temática
- Organização de um projeto web

## 🌱 Minha evolução

Por ser um dos meus primeiros projetos, ele possui uma estrutura mais simples e representa uma etapa inicial da minha jornada no desenvolvimento web.

Hoje, continuo estudando e desenvolvendo novos projetos, buscando aprimorar meus conhecimentos e criar aplicações cada vez mais completas.

Este projeto representa justamente uma parte desse começo: **aprender programação de uma maneira criativa e colocando meus interesses em prática.**
